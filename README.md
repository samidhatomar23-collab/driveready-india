# DriveReady India (Phase 1 MVP)

Mobile-first, installable, offline-capable practice app for Indian Learner's Licence (LL) theory tests, with a Duolingo-style learning path (original branding: "Coney" the traffic cone, teal/amber palette).

> Independent practice app, not affiliated with MoRTH, Parivahan, Sarathi or any RTO. Always check official sources for current rules.

## What's in Phase 1
Onboarding (language, state, vehicle, daily goal) - learning path with 3 units (Road Signs, Right of Way, Signals & Markings) and unit checkpoints - lesson player (multiple choice, sign identification, true/false, match-the-pairs) with hearts, XP, levels, streak + freeze, mistake re-queue - Practice tab (spaced repetition, weak topics) - strict **Real Test Mode** (per-state rules, per-question timer, no going back, review) - Signs library (search, flashcards, "Guess the sign") - Profile dashboard, settings (dark mode, large text, sound) - About/Privacy. English + Hindi toggle on every question.

**Not yet built (Phase 2/3):** remaining 7 units, Track Simulator, hazard-tap / drag-order / fill-in question UIs, fines & application-guide screens, ingestion pipeline, leagues, accounts/sync. The 300-question target needs the Phase 2 ingestion + review; Phase 1 ships 89 sample items.

**Content caveat:** all questions, state test settings and sign images are placeholders/unverified. See `SOURCES.md`.

## Setup
```bash
npm install
npm run dev              # http://localhost:5173
npm run validate:content # sanity-check all JSON
npm run build && npm run preview
```
Node 20+.

## Deploy
* **Vercel:** import the repo; framework "Vite"; `vercel.json` handles SPA rewrites.
* **Netlify:** build `npm run build`, publish `dist`; `netlify.toml` handles redirects.
The service worker (vite-plugin-pwa) precaches the app and content for offline use. The app needs HTTPS to install.

## Extending
* **Questions:** add objects (schema in `src/types.ts`) to `src/data/questions/<unit>.json` with a valid `lessonId`; run `npm run validate:content`. Phase 1 content is generated by `scripts/seed/build-sample-content.mjs` - re-running it overwrites the JSON, so either edit the script or stop using it once you hand-edit the JSON.
* **Units/lessons:** `src/data/units.json`; register a new unit's question file in the `loaders` map in `src/lib/content.ts`.
* **States:** add an entry to `src/data/states.json` (`llTest.questionCount`, `passMark`, `secondsPerQuestion`). Set `verified:true` only after checking the official portal.
* **Languages:** add `src/data/i18n/<code>.json`, extend `Lang` in `src/types.ts` and `dicts` in `src/lib/content.ts`, add per-question `languages.<code>`; missing text falls back to English.
* **Sign artwork:** replace `SignGraphic` output with official/licensed images and set `imagePlaceholder:false`.

## Notes
* Local-first: progress lives in IndexedDB; no account, no network needed after first load, no personal data collected.
* Fonts: system fonts (Nunito if installed). Self-host Nunito + a Devanagari font in `public/` for consistent rendering.
* Main JS bundle is ~150 KB gzipped; question JSON is code-split per unit.
