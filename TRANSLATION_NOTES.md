All Hindi, Marathi, Telugu and Tamil text was drafted by Claude and has NOT been reviewed by a native speaker. Please have each language checked before relying on it for a public release. Keep the meaning of each answer exactly as in English.

## Marathi

- Hearts (game lives) translated as जीव (lives); a native speaker may prefer हृदय.
- Roundabout = वर्तुळाकार चौक; many learners may say रोटरी or गोल चक्कर.
- Right of Way unit title = मार्गाचा अग्रक्रम; check if a more common RTO phrase exists.
- Mandatory/Cautionary/Informatory = आदेशात्मक / सावधगिरीची / माहितीदर्शक (chosen to match Marathi RTO booklets).
- Prohibited rendered as निषिद्ध throughout; मनाई/प्रतिबंधित are alternatives.
- Staggerd junction ahead = पुढे एकमेकांपासून सरकलेला चौक (unsure of the standard Marathi term).
- No thorough road = आरपार रस्ता नाही (dead end / no through road).
- True/False options = बरोबर / चूक (alternative: खरे / खोटे).
- Streak freezes = सलग दिवस संरक्षण (unsure of natural gaming term).
- Units written as किमी/तास.
- Autorikshaw rendered as ऑटोरिक्षा; Students prohibited translated literally as विद्यार्थी निषिद्ध.

## Telugu

- Hearts (lives) rendered as హృదయాలు; native speaker may prefer another word such as ప్రాణాలు or లైవ్స్.
- Pass/Fail: PASSED = పాస్, NOT PASSED = పాస్ కాలేదు (common spoken usage).
- True/False rendered as ఒప్పు / తప్పు; alternatives are నిజం / అబద్ధం.
- ascend/descend sign names rendered as ఎత్తు రోడ్డు / వాలు రోడ్డు (road goes up / slopes down); please verify wording.
- median rendered as డివైడర్ (common usage); Staggered junction rendered as ఎడంగా ఉన్న రోడ్ల కూడలి; please verify.
- Hump rendered as ఎత్తు (హంప్); Y-intersection as వై-జంక్షన్.
- test.rules 'Test rules for' is a prefix label in English; Telugu word order would put the state first, so it is rendered as a plain heading పరీక్ష నియమాలు.
- Stop sign name rendered as ఆగండి; STOP kept in Latin only where it is the printed text on the sign.
- Signal vs signs: 'signs' = సంకేతాలు, traffic 'signals' = సిగ్నళ్లు; goal names (Casual/Regular/Serious/Intense) rendered as తేలికగా/క్రమం తప్పకుండా/శ్రద్ధగా/తీవ్రంగా.

## Tamil

- Hearts (game lives) translated as உயிர்கள் (lives); native speaker may prefer இதயங்கள்.
- True/False rendered as சரி/தவறு (alternative: உண்மை/பொய்).
- Streak freezes rendered as தொடர் நாள் பாதுகாப்பு; check that it reads naturally.
- Stop sign name uses நிறுத்து (STOP) with STOP kept as printed on the sign.
- Y-junction/T-junction written as ஒய்-சந்திப்பு / டி-சந்திப்பு; U-Turn as யு-டர்ன்.
- 'Staggerd junction ahead' rendered as இடம்மாறிய சந்திப்பு; 'No thorough road' as ஊடுசெல்ல முடியாத சாலை (dead end / no through road).
- 'Students prohibited' (odd source phrase) translated literally as மாணவர்களுக்குத் தடை.
- Weighbridge rendered as எடை மேடை; Ghat road as மலைப்பாதை.
- km/hr written as கி.மீ/மணி.
